- (decision) 최신 PRD와 addendum을 함께 UX 기준 문서로 사용한다.
- (decision) 이용자가 신뢰할 수 있고 지속적으로 이용할 수 있는 경험을 최우선 UX 품질로 삼는다.
- (decision) 사용자 승인에 따라 fast path로 진행한다.
- (decision) 제품 표면은 한국어 반응형 웹이며 모바일 웹 대시보드를 대표 진입으로, 데스크톱을 동등 지원한다.
- (decision) 신뢰 정보 위계는 마지막 정상 현재가치와 측정 시각, 신선도, 입력 신뢰도, 계산 성격을 핵심 지표보다 먼저 제시한다.
- (decision) 세 신뢰 축은 하나의 종합 배지로 합치지 않고 각각 상태명, 원인, 마지막 정상 시각, 다음 행동을 제공한다.
- (decision) 지속 이용은 스트릭이나 알림이 아니라 짧은 재방문, 계획과 조정 이력의 영속성, 장애 후 복귀 가능성으로 설계한다.
- (decision) 핵심 IA는 인증, 온보딩, Bybit 연결 검증, 계획 생성, 대시보드, 신뢰 상세, 조정 이력, 계획 종료·완료, 연결·개인정보 설정, 서비스 제한 상태로 구성하고 운영자 제어는 별도 보호 표면으로 분리한다.
- (decision) 수동 동기화 결과는 기존 스냅샷을 유지한 채 진행 상태를 보이고, 성공한 원자적 스냅샷 전체를 한 번에 교체한다. 실패 시 마지막 정상값을 유지한다.
- (decision) 광고는 금융 정보가 없는 중립 전환 표면에서만 요청하며 닫기·실패·미채움·동의 거부 뒤 결과 조회를 막지 않는다.
- (assumption) 별도 UI 시스템이 없으므로 WCAG 2.2 AA를 바닥으로 하는 커스텀 토큰 시스템을 사용한다.
- (assumption) 브랜드 시각 언어는 차분하고 검증 가능한 금융 기록 도구로 가정한다. 과장된 수익 그래프, 네온 트레이딩 미학, 축하·공포 연출, 성과 게임화를 사용하지 않는다.
- (assumption) MVP는 라이트 모드를 기본으로 명세하고 다크 모드는 후속 결정으로 남긴다.
- (assumption) 인증 방식, 지원 채널, 광고 공급자와 빈도 제한은 PRD 미결정 사항을 상속하며 UX 계약에서 특정 구현을 확정하지 않는다.
- (change) 전체 검증을 실행했으며 rubric, 접근성, 금융 신뢰·개인정보 렌즈의 발견사항을 문서에 반영했다.
- (decision) MVP는 오프라인 금융값 표시와 지속 브라우저 캐시를 제공하지 않는다.
- (decision) 광고 동의 전 제3자 SDK와 네트워크 요청을 금지하고 공급자 미확정 시 광고 없이 베타를 출시한다.
- (decision) 계산 근거 화면에서 스냅샷 ID, 공통 기준시점, 측정 시각, 계산 버전과 조정 이력 버전을 연결한다.
- (decision) 전역 focus-visible, 단일 live region, 광고 iframe 밖 즉시 닫기, 400% 확대와 320px 리플로를 접근성 하한으로 확정한다.
- (event) 전체 UX 검증 및 post-fix 재검증 완료: 잔여 high 1 인증 결정, medium 1 광고 공급자 실제 보조기술 승인 시험.
- (override) 인증 방식 미결정 가정을 폐기하고 공개 베타에서 Google·Naver·Kakao 3개 OIDC 소셜 로그인을 지원한다.
- (decision) 소셜 계정은 본인 확인에만 사용하며 내부 사용자는 issuer+subject로 식별한다. 이메일 일치 자동 병합은 금지하고, 추가 로그인 수단은 현재 수단 재인증과 새 제공자 인증을 모두 거쳐 명시적으로 연결한다.
- (decision) Bybit 연결 생성·교체·해제, 로그인 수단 연결·해제, 계정 삭제, 의심 세션 이후에는 연결된 소셜 제공자로 최근 인증을 요구한다.
- (override) 내부 사용자 식별은 issuer+subject 자체가 아니라 BokriLog user_id가 소유한다. 제공자별 (issuer, subject)는 유일한 외부 로그인 레코드로 하나의 user_id에 1~3개 매핑하며 이메일은 식별·자동 병합에 사용하지 않는다.
- (event) Google·네이버·카카오 소셜 인증 결정 반영 후 집중 재검증 완료: rubric 8개 범주 strong, 인증 관련 Critical/High/Medium/Low finding 0.
- (override) 광고 공급자 미확정 시 광고 없이 출시한다는 이전 기본값을 폐기한다. 공개 베타는 무료·유광고 모델이며 공급자·동의·데이터 흐름 확정과 실제 접근성 승인 시험을 출시 필수 게이트로 둔다.
- (decision) 계정 삭제 시 소셜 연결·Bybit 자격정보·사용자 금융·계획·계산 데이터와 광고 동의를 삭제하고 세션을 종료한다. 다른 법령이 요구하는 최소 보안·관리자 접속기록만 분리 보존하며 정확한 기간과 백업 파기 기한은 출시 전 법률 검토로 확정한다.
- (event) 무료·유광고 베타 결정 반영 후 접근성 집중 재검토 완료: 문서 모순과 추가 finding 없음. 실제 공급자·소재 승인 시험 Medium 1은 출시 전 실행 게이트로 유지.
- (decision) MVP 시각 방향은 차분한 장부형 라이트 모드와 커스텀 토큰 계약으로 확정하며 다크 모드는 후속 대비 검증 범위로 둔다.
- (decision) 핵심 시각 참조는 소셜 로그인, 모바일 대시보드 정상 상태, 입력 신뢰도 검토 필요 상태, 수동 동기화 후 중립 광고 전환 4개 HTML 목업으로 제한하고 나머지 IA 표면은 spine-only로 구현한다.
- (decision) 광고는 비개인화 문맥형으로 수동 동기화 성공 뒤 최대 30분에 1회, 하루 최대 3회 시도한다. 공급자 선정은 구현 단계로 넘기되 실제 소재 접근성·개인정보 승인을 베타 출시 게이트로 둔다.
