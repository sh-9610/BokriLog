BokriLog 최종 인프라 권고안 재검증

OCI A1 단일 서버 + Spring Modulith + PostgreSQL + Grafana Cloud 구성을 신뢰성, 보안·복구, 자원·관측성 관점에서 독립 검토했습니다.

조건부 통과
큰 방향은 적합합니다. 아래 필수 수정 5건을 반영하면 포트폴리오와 초기 공개 베타에 사용할 수 있습니다.
P0 · 최신 한도

A1은 2 OCPU / 12GB 기준

무료 전용 계정의 최신 공식 한도입니다. 4/24GB는 tenancy 또는 PAYG 무료 적용이 콘솔에서 확인될 때만 사용합니다. 배포 전 Always Free 표시와 예상 비용 $0를 확인합니다.

P0 · 고정 주소

Reserved public IPv4

Bybit IP 화이트리스트를 위해 ephemeral IP 대신 리전 고정 IP를 VNIC에 연결합니다. 복구 시 같은 리전 VM에 재할당한 뒤 송신 IP와 동기화를 검증합니다.

P0 · 복구 가능성

키와 백업은 OCI 밖에도

암호화 dump를 OCI와 별도 저장소 두 곳에 보관하고, 애플리케이션 key ring과 백업 키도 OCI 밖 비밀번호 관리자에 둡니다. 월간 복원에서 실제 복호화까지 확인합니다.

P0 · 관측성

AD-14 단일화 + 외부 생존 확인

개발은 self-hosted, 운영은 Alloy + Grafana Cloud로 확정합니다. 외부 synthetic가 /health/live를 5분마다 확인하고 telemetry 부재도 경보합니다.

P0 · 운영 등급

24×7 실행 목표와 가용성 보장을 구분

Always Free에는 idle 회수, capacity 부족, SLA·지원 부재 위험이 있습니다. 따라서 24×7 상시 실행 목표, best-effort, SLA 없음으로 표현하고, 최초 회수·8시간 capacity 실패·유료 사용자 발생 시 PAYG 또는 유료 VPS로 옮깁니다.

유지

타당한 결정

  • Spring Modulith 모듈형 모놀리스 + 별도 Worker
  • PostgreSQL 작업 큐 우선, broker/outbox는 확장 경로
  • Bybit totalEquity 권위 입력
  • 배포 시에만 blue/green
  • 운영 서버에서 테스트 도구 제외

RPO / RTO

  • RPO: 공개 베타에서 최대 24시간을 명시적으로 수용
  • RTO: A1 capacity 때문에 best-effort
  • 복원 성공: DB뿐 아니라 키, 자격 증명 복호화, 세션 폐기, reserved IP, Bybit smoke까지

구현 승인 게이트

  • OCI 콘솔에서 home region, entitlement, capacity, $0 확인
  • reserved public IPv4와 Bybit IP 검증
  • AD-14를 개발 self-hosted / 운영 Grafana Cloud로 단일화
  • OCI 밖 key 사본과 두 번째 암호화 백업
  • 외부 synthetic와 telemetry absence 경보
  • ARM64 동일 digest 배포 피크 smoke
  • RPO 24h, best-effort RTO, 유료 호스트 전환 조건 문서화
